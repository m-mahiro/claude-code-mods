# btw-fix

`/btw`（現在の作業を中断せずに聞ける side question 機能）は、回答を待っている間メインの会話がスクロールできなくなり、その画面を閉じると回答がキャンセルされてしまう。

この mod は `/btw` を自前の実装で肩代わりする。`command.run` を `{ command: 'btw' }` でフックし、`next()` を呼ばずに答えてしまうことで、ブロッキングなサイドパネルを使うビルトイン実装そのものを素通りさせる。回答は普通のトランスクリプトの行として出る（`$.model.fork` で、現在の会話を文脈にしたツールなしの一回限りの応答を取り、それをコマンドの出力テキストとして返すだけ）ので、ロックするパネルも、閉じて中断するものも存在しない。

## 使い方

`/btw <質問>` は今まで通り。質問が空なら使い方を返す。

## 試す

```sh
claude plugin validate mods/btw-fix
claude plugin test mods/btw-fix
```

セッションでホットリロードを有効にして実機で試す場合は、このフォルダをそのまま dev-mods フォルダ（`plugin-authoring` スキルが教える場所）にコピーすればよい。
